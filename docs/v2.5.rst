Overview
--------

This project normalizes whitespace.

Installation
------------

To install this project, you can use ``pip``.
Open your terminal and run:

.. code-block:: shell

    pip install jacobus

Typing
------

This project is strictly typed with ``mypy``.

``run(*filepatterns: str, empty: int | None = None, exclude: Iterable[str] = (), indent: int | None = None, sort: bool = False, unique: bool = False) -> None``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

This function finds all the files that match one of the ``filepatterns``.

If ``exclude`` is given, files that match any of its glob patterns are excluded from processing, even if they match a ``filepatterns`` pattern explicitly.
Both inclusion and exclusion patterns support recursive globbing with ``**``.
By default, ``exclude`` is empty and no files are excluded.
Pass an iterable of pattern strings, not a single string.
To exclude the contents of a directory, use a pattern such as ``generated/**`` rather than just ``generated``.

For example:

.. code-block:: python

    from jacobus import run

    run("**/*.py", exclude=("generated/**", "**/setup.py"))

The corresponding CLI option is ``--exclude``, which can be given once per pattern.
Quote glob patterns on the command line to prevent the shell from expanding them.

.. code-block:: shell

    python -m jacobus "**/*.py" --exclude "generated/**" --exclude "**/setup.py"

Then, it removes unnecessary whitespace.

Lastly, if an ``indent`` is given, the previous indentation is corrected.
